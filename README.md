# Smart Waste Management System 🌍

A comprehensive **Smart Waste Management System** designed to optimize waste collection and disposal processes using IoT and AI. This repository includes Figma designs for the admin portal, waste collector portal, and resident portal for the application.


## 📝 Overview

The Smart Waste Management System leverages IoT sensors to monitor bin capacity, optimize routes for waste collection, and notify relevant stakeholders (residents and waste collectors). The system aims to promote efficient waste management and reduce environmental impact.

### Key Features:
- **Admin Portal**:
  - Monitor bin statuses and view system analytics.
  - Assign drivers and manage waste collection schedules.
  - Optimize collection routes based on bin capacity and location.
  - View residents
  - View staff and hire new staff
  - View vehicles and add new vehicles
  - Approve Leave requests
  
- **Waste Collector Portal**:
  - View assigned tasks and routes in real time.
  - Receive notifications for bins that are 80% full.
  - Apply for leave
  
- **Resident Portal**:
  - Register a new bin for waste collection.
  - Provide feedback on waste management services.
  - Track bin collection history and nearby bin locations.
  - View feedback responses
